HOW WE CHOOSE

折扣不是结论。使用需求、总成本与退出成本，才决定一件东西是否值得。

01 / 先分清证据，再看购买建议

“值得关注”是对适用场景的判断；“已读官方原文”只表示正文中的数字、条件得到核对。它们不能互相替代。

  • 官方正文：读到实际活动页、价目表、政策或产品页；仍不能保证所有地区和账户同价。
  • 官方检索摘要：只见索引文字，未读到完整细则；购买前必须到原页面核对。
  • 媒体报道：由具名媒体转述，不提升成官方已核实。
  • 未能核实：页面阻挡、规则缺失或尚未公布；作为待查条目收纳。

状态另分当前可用、即将开始、全年常规、已结束、待核实。按2026-11-11快照整理，没有证据不写2026黑五活动已开始。

02 / 到手价与一年后的账单

首期总成本 = 商品价 − 实际生效优惠 + 运费 + 税费 + 必需配件

订阅或VPS再补算：第二年续费 + IPv4 + 超额流量 + 备份 + 支持费用。价格标成“$2/月，年付”时，通常意味着一次付款约$24，不代表能每个月付$2。

  • 同款同容量、同保修、同配送范围才可直接比较。
  • “最高省80%”要看比较的是原价、套餐价还是多年总价。
  • 新客、学生、区域账户、支付卡要求不符合，就不能把优惠算进预算。
  • 年付和多年付前先看取消、退款、自动续费和迁移难度。

03 / VPS、云主机与存储怎么选

用途优先看需要避开
学习 / 轻量博客可月付、快照、文档、基础资源只为促销年付闲置多台
大陆访问目标运营商晚高峰实测、延迟/丢包用CN2/CMIN2名字代替实际测试
生产业务可恢复备份、支持、故障策略、资源稳定只因低价选无SLA小商多年付
冷备份容量、取回、下载流量、版本控制把对象存储当成实时文件系统
域名 / 邮件续费、转出、恢复期、邮件可投递性只看第一年注册价

核对：vCPU是共享还是专用、RAM是否真实保证、SSD/NVMe容量、流量按单向还是双向计算、端口速率与公平使用、IPv4是否另收、IPv6/NAT限制、机房、退款窗口、税、付款周期、续费价、商业使用许可。

线路名称、标称1Gbps和“无限流量”都不能代替性能测量。此目录没有做跨运营商全天测速，因此不替任何商家承诺“最稳/最快”。

04 / 这些情况，列进“不建议追”

  • 相对常态价只便宜一点，却要求凑单、多年预付或牺牲退货权。
  • 低价首期后续费暴涨，且数据迁移成本很高。
  • 所谓终身订阅没有明确服务生命周期和数据导出途径。
  • 型号相似但配置缩水，套装附赠物并不是你需要的。
  • 酒店房券不能预约目标日期，热门日加价后比直接预订更贵。
  • 账号共享、虚假学生认证、来历不明的软件序列号或充值卡。

不建议追不等于产品一定差；它表示在本条描述的价格、条件和使用需求下，不足以构成购买理由。
